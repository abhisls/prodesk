### 📖 About This Project

RPSC Notes is a free educational website providing high-quality notes for:
- Rajasthan GK (History, Geography, Polity, Culture, Economy)
- Mathematics & Science (Physics, Chemistry, Biology, Maths, Reasoning)
- Previous Year Questions (PYQ 2018-2024)
- Daily Current Affairs

This website is made for students preparing for RPSC 1st Grade and 2nd Grade Teacher exams.
